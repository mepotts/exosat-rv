## The manuscripts

[`paper/`](paper/) holds the drafts. Each `.md` or `.template.html` is **source**; the matching
`.html` is a **build product** — never hand-edited, regenerated by
[`../scripts/m16_build_paper.py`](../scripts/m16_build_paper.py) and
[`../scripts/m33_render_notes.py`](../scripts/m33_render_notes.py).

- `draft.template.html` — the manuscript.
- `rnaas-etatel-draft.md` — the η Tel B note.
- `contrast-wall-note.md`, `methods-note.md`, `sampler-reproducibility-note.md` — the supporting notes.
- [`paper/joss/`](paper/joss/) — the JOSS software-paper submission and its release checklist.
- `paper/author-query-draft.md` — a query to the corresponding author. **Not sent**; sending is
  gated on Matthew, like everything outward-facing (`LESSONS.md` §6).
