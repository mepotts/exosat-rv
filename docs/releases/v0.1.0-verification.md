Python 3.12.3 virtual environment under Ubuntu/WSL installed build tooling and the declared
dependencies. `python -m build` built the source distribution and then the wheel from that
source distribution, using `build==1.6.0` and `hatchling==1.32.0`.

The wheel was installed before switching to an editable installation. From an otherwise empty
directory, CLI help succeeded, default storage resolved to the caller's `data/` without
creating it on import, and `EXOSAT_DATA_DIR` pointing at the source data allowed the published
table loader to read all 23 rows. This loader smoke checks packaging/path behavior; it is not
independent scientific validation. Research data and campaign scripts are not in the wheel.

## Historical downstream replay

The full M37 command ran with its defaults: 5,000 permutations and a 4,000-point period grid,
writing to a temporary output instead of overwriting the retained audit. It reproduced the
screened/all-night conclusions. Recursive comparison against the committed JSON found no
differences beyond relative tolerance `1e-10` and absolute tolerance `1e-8`; the maximum
absolute numerical difference was approximately `1.10e-9`. Only the declared Python and
NumPy version strings were excluded from comparison. Source identities and methodological
fields were compared too.

The new environment used NumPy 2.5.2, SciPy 1.18.1, and Astropy 8.0.1; it is an observed
verification environment, not a reconstruction of the missing historical extraction
environment or a promise of bit-identical results on every numerical platform.

## Review and remaining limitations

An independent agent reviewed the release diff against `427e151`, including claims,
packaging, CLI changes, tests, and CI. It reported no P0–P2 finding. Its P3 observation that
the JOSS draft still described lint as absent from CI was corrected. This is an internal
software/claim audit, not an external scientific replication.

The full historical script collection is **not lint-clean**: Ruff 0.15.6 reports 287 findings,
principally compact statement formatting, import placement, ambiguous local names, and unused
code. They are disclosed rather than suppressed or mechanically rewritten across scientific
history. A separate undefined-name/syntax scan (`F821,F822,F823,E9`) passed, and the eight
report-header compatibility repairs preserve their full Python ASTs while allowing Python
3.11 parsing. CI now enforces package/test lint and compilation of package, tests, and scripts
on Python 3.11 and 3.12. Passing compilation does not test every historical script's runtime.

The existing WSL environment initially needed an explicit source import path, and the first
fresh build exposed seven citation-test formatting findings under the newer Ruff defaults;
both were resolved before the successful clean run. An initial temporary verification
directory was unavailable in a later WSL call, so verification was repeated with its report,
archives, log, and replay output retained under the ignored `dist/verification-6a58e47/`.

Live archive services, fresh raw reduction, external fitted-template reconstruction,
manuscript completeness, and M38's observational/scientific validation are outside this
verification. No GitHub Release, tag, DOI, dataset deposit, or manuscript submission is
declared by these checks. The reviewed scope remains a development software and qualified
reanalysis snapshot.
