# v0.1.0 — development software and qualified reanalysis

Status: release candidate prepared in the repository; no release date or DOI is declared
here. Version `0.1.0` is retained for the first development snapshot. It does not promise a
stable API, establish a new detection, or report an executed M38 science experiment.

## Included scope

- Python archive, spectrum-conversion, orbital-analysis, and feasibility tools; the raw
  extraction campaign remains separately documented scripts requiring external cr2res/VIPER.
- The M37 audit and frozen M14/M15 RV/per-order evidence in `data/repro/`, including file
  hashes and explicit limitations on historical settings and external templates.
- M38 generic injection, template, selection, search, calibration, provenance, and runtime
  infrastructure with synthetic tests. Instrument realism, observational control truth,
  scientific thresholds, and the target experiment remain unvalidated.

The extracted RVs were derived from spectra with configurations selected using numerical
agreement with the published RVs. The near-171-day result is conditional on the internal
17-night screen; the complete 18-night BERV-adjusted searches are compatible with noise.
Fitter-stage injection recovery does not validate signal survival during template creation.
The second-companion non-reproduction applies only to the models and priors tested here.
See [M37](../milestones/M37-RESULTS.md) for the controlling scientific account.

## Preparation changes

- Reconciled M34's interpretation with M37: configurations with a surviving period do not
  rule out tuning effects, broad observing-mode transfer was withdrawn, and M36 was
  target-aware and invalid as a preregistered execution.
- Updated publishing guidance to distinguish software archiving from manuscript readiness.
- Fixed the inventory CLI's missing epoch-count attribute and qualified its help text.
- Added `EXOSAT_DATA_DIR`; installed wheels use the caller's data directory instead of a
  location inferred inside the Python environment. Editable checkouts retain their local
  `data/` directory. Set the override before launching the CLI.
- Excluded extracted third-party paper text and unsent correspondence from Git source
  archives and Python source distributions. Existing Git history is unchanged; these files
  are not thereby removed from GitHub. The MIT license covers project software, not the
  third-party literature. No separate dataset license or deposit is created by this release.

## Installation and reproducibility

Follow the [README quickstart](../../README.md#quickstart). The source release includes
scripts, tests, metadata, and the small downstream evidence bundle. The wheel contains only
the Python package. Supply the source release's data directory through `EXOSAT_DATA_DIR`
when running data-dependent commands from a wheel installation.

Offline integrity and rendering checks are:

```bash
python scripts/m37_package_evidence.py --verify
python scripts/m37_render_results.py --check
```

To recompute the historical downstream audit without replacing its retained artifact:

```bash
python scripts/m37_reaudit.py --output build/m37-reaudit.json
```

That calculation uses bundled derived RV tables. It is not an M38 target execution or a new
raw reduction. A full historical raw-exposure-to-template replay remains unavailable: the
raw/reduced spectra and fitted templates are external, and contemporaneous environment and
effective-setting records were not captured. Current verification does not reconstruct that
missing history. See the [verification record](v0.1.0-verification.md) for actual checks,
environment, exclusions, and any outstanding findings.

## Before publication

Publish only the reviewed candidate and its matching release notes. The actual release date
and DOI must be recorded when those events occur; an ORCID must come from the author and is
omitted until supplied. A GitHub push or merge does not itself create a tagged Release,
Zenodo record, journal submission, or author correspondence.

The separate M38 validation project remains open: independent control truths, a realistic
production adapter and full-template injection experiment, calibrated uncertainty and false
positives, a frozen protocol/runtime, and independent review before target access. Completing
that experiment is not a prerequisite for transparently archiving this limited software
snapshot.
