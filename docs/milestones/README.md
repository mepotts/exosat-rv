# Milestone records

One document per milestone, each owning a conclusion. A later milestone can overturn an
earlier one -- several do -- and when that happens the superseded document is amended to say
so rather than deleted, because the wrong turn is part of the record.
[`../LESSONS.md`](../LESSONS.md) §7 maps which document owns which conclusion; this table is
the roster, in the documents' own words.

**Numbers are not contiguous.** M16, M18, M19, M21, M22, M24, M25, M26, M27, M33 have no document:
the number was spent on work that landed inside another milestone, or on a thread that was
abandoned. Before writing a new one, check the number is free — see `../LESSONS.md` §5d.
